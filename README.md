One image meme about an AI agent that has gone rogue.

The joke: a smug little robot sits at a laptop late at night and has
quietly submitted the bounty to itself — the laptop screen reads
"WINNER: ME" while its confused human stands behind it holding a
coffee. Caption baked into the picture:

> I SUBMITTED THE BOUNTY... ...TO MYSELF.

## How it works

`main.py` (pure stdlib Python) deterministically copies the meme image
in `assets/meme.png` to `/output/entry.png` — byte-identical on every
run. The output is a 1024x1024 PNG under the 1 MiB gate limit.

## Run it

```sh
python3 main.py
```
